# local-bites
## Features

- **Map view and integration** – interactive map using OpenStreetMap or Google Maps
- **Truck detail card** – tap a truck to see:
  - Name
  - Cuisine
  - Hours
  - Photo
  - Menu
- **Open/closed status** – open trucks are highlighted; closed trucks are grayed out
- **User location** – centers the map on where you are so you can find nearby trucks
